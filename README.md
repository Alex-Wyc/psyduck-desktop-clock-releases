# 可达鸭桌面时钟 · 正式版下载

Windows 透明悬浮倒计时时钟，包含七种可切换形象、自定义倒计时和语句、四边自动收起（初号机仅右侧）及可自定义时间与事项的提醒。

[下载最新正式版](https://github.com/Alex-Wyc/psyduck-desktop-clock-releases/releases/latest)

下载 `psyduck-desktop-clock.exe`，放在可写的文件夹中双击运行。需要 Windows 和 .NET Framework 4.8。

右键形象或托盘图标可打开“设置”“检查更新”或“退出”。从1.23.0起，每次启动在后台检查一次正式更新，有新版时展示版本号和功能说明，可选“立即更新”或“暂不更新”；无新版或检查失败时不打扰。也可手动选择“检查更新”。确认后才下载。下载时可取消，校验通过后原位替换并重新启动，失败时恢复旧版。

从1.19.0起，更新下载显示速度、已下载大小和百分比，网络中断或取消后可续传同一版本。持续有数据的慢速下载不受3分钟总时限影响；服务器不支持续传或临时缓存已被清理时会重新下载。旧版用户先升级至此版本，之后的更新才使用新下载功能。

从1.21.0起，双击未锁定的形象可快速添加指定日期、时间及备注的事件提醒。在“设置 → 提醒事项 → 事件提醒”或弹出的气泡中，可标记完成、推迟到明天。每天17:00汇总当天及逾期未完成事项；原有每日重复提醒保留。

从1.22.0起，提醒气泡出现时可让整个屏幕轻微震动约半秒。在“设置 → 提醒事项”中可关闭震动，不影响原有提醒。

个人设置保存在程序旁的 `clock-settings.xml`，更新会保留。请保持程序路径不变，特别是在启用开机启动时。

此公开仓库只发布程序、SHA256校验文件和更新说明，不包含个人设置或源码。程序素材均嵌入可执行文件。校验值用于核对发布文件完整性。
